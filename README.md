# Andreea Nistor Portfolio

Static portfolio website for GitHub Pages.

## Preview locally

Open `index.html` in a browser. The site has no build step or package dependencies.

## Publish on GitHub Pages

1. Create a public GitHub repository named exactly `andreea-nistor.github.io`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open the repository's **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Visit `https://andreea-nistor.github.io/` after deployment completes.

`PORTOFOLIU_GITHUB.md` is a planning document and does not need to be published with the website.

## Update content

- Personal and project content: `index.html`
- Colors, typography, and responsive layout: `styles.css`
- Mobile navigation and reveal behavior: `script.js`

The AI DocuSearch preview embeds the live Streamlit application. If Streamlit is sleeping, the preview may take a moment to load; the **Open the live application** link remains available.
